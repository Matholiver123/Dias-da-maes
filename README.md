# Dias-da-maes

Projeto em Java criado para homenagear as mães de forma simples e interativa utilizando Programação Orientada a Objetos.

## Sobre o projeto

O sistema permite que o usuário:

- Digite o nome da mãe
- Escolha um presente
- Escreva uma mensagem personalizada
- Gere uma homenagem final no terminal

O projeto foi desenvolvido com foco em prática de:

- Classes e objetos
- Encapsulamento
- Organização de código
- Entrada de dados com Scanner
- Estruturas condicionais
- Programação Orientada a Objetos (POO)

## Estrutura do projeto

- `Main.java` → Inicialização do sistema
- `SistemaHomenagem.java` → Controle principal do programa
- `Mae.java` → Dados da mãe
- `Mensagem.java` → Mensagem personalizada
- `Presente.java` → Presentes disponíveis

## Tecnologias utilizadas

- Java
- Visual Studio Code
